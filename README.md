# Human Population Analysis Dashboard (Power BI)

An interactive Power BI dashboard analyzing global and regional human population trends, demographics, and metrics.

## 📊 Overview

This repository contains the Power BI report (`.pbix`) file for the **Human Population Analysis Dashboard**.

- **File**: `Human Population Analysis Dashboard.pbix`
- **Tool**: Microsoft Power BI Desktop

## 🚀 How to View the Dashboard

1. **Prerequisites**: Install [Power BI Desktop](https://powerbi.microsoft.com/desktop/) (free).
2. **Download / Clone** this repository:
   ```bash
   git clone https://github.com/Aditya4426g/human-population-powerbi-dashboard.git
   ```
3. Open `Human Population Analysis Dashboard.pbix` in Power BI Desktop.
4. Interact with the visuals, slicers, and demographic metrics.

## 💡 Features
- Interactive population growth and demographic trends
- Country/regional breakdown and comparisons
- Demographic distributions and KPI summaries
